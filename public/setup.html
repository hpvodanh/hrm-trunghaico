Bước 1: Chuẩn bị Google Cloud Project & Service Account

Hệ thống HRM TRUNG HẢI sử dụng Google Sheets làm Cơ sở dữ liệu Cloud độc quyền của riêng bạn. Hãy thực hiện 3 thao tác đơn giản sau trên tài khoản Google của công ty:

1 Tạo Google Cloud Project & Bật API
Truy cập Google Cloud Console, tạo một Project mới (ví dụ: hrm-company-db), sau đó vào mục APIs & Services > Library và bật (Enable) 2 API sau:
Google Sheets API và Google Drive API
2 Tạo Service Account (Tài khoản dịch vụ)
Vào IAM & Admin > Service Accounts > bấm Create Service Account. Đặt tên (ví dụ: hrm-sheet-service), cấp quyền Role: Editor và nhấn hoàn tất.
3 Tải Khóa riêng tư (Private Key JSON)
Nhấp vào Service Account vừa tạo > chọn tab Keys > bấm Add Key > Create new key > JSON. Một file *.json sẽ tự động được tải về máy tính của bạn.

Bước 4: Chọn Cấu hình Dữ liệu Ban Đầu

Hệ thống sẽ tự động khởi tạo 14 tab dữ liệu chuẩn theo mô hình dữ liệu doanh nghiệp. Hãy chọn chế độ bạn mong muốn:

Bộ Dữ Liệu Doanh Nghiệp Mẫu
Tạo sẵn 1,000 nhân sự, 28 phòng ban, 113 vị trí, hợp đồng và bảng lương chuẩn để bạn và khách hàng trải nghiệm ngay tất cả biểu đồ & tính năng.
Cơ Sở Dữ Liệu Trắng Tinh
Khởi tạo cấu trúc 14 tab chuẩn nhưng **không có dữ liệu mẫu** (chỉ có 1 tài khoản Super Admin) để công ty tự nhập mới nhân sự từ đầu.
